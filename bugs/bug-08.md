# BUG-08: Эвдэрсэн JSON бүхий ном нэмэх хүсэлт HTTP 400-ийн оронд 200 OK буцаадаг

- **Орчин:** «Уншлагын жагсаалт» v2.0, Ubuntu Linux, Node.js сервер, curl; браузер шаардахгүй.
- **Session-ийн тэмдэглэлийн цаг:** 2026-10-17 00:20:52, UTC+08:00.
- **HTTP хариуны Date:** 2026-10-17 00:21:15, UTC+08:00.
- **Олдсон аялал:** Saboteur.

## Урьдчилсан нөхцөл

`node app.js`-ийг шинээр асаасан, сервер localhost:3000 дээр ажиллаж байна. Терминал репозиторийн үндсэн хавтсанд байна. Session-ийн эх нотолгоо `evidence/api-invalid-json.txt` дотор хадгалагдсан.

## Дахин гаргах алхам

1. Сервер ажиллаж байгааг шалгана.
2. Доорх командыг ажиллуулна. Хүсэлтийн body нь төгсөөгүй JSON юм.

```bash
curl -i -X POST http://localhost:3000/api/books \
  -H 'Content-Type: application/json' \
  --data-binary '{"title":'
```

3. HTTP статусын мөр болон хариуны body-г уншина. Давтан шалгалтын нотолгоог файлд хадгалах бол шинэ нэр ашиглаж, session-ийн эх нотолгоог дарж бичихгүй.

## Хүлээгдэж буй үр дүн

Спецификацийн «буруу JSON биетэй POST хүсэлтэд 400 алдаа буцаана» дүрмийн дагуу HTTP 400 байна. Хүсэлтийг амжилттай мэт хариулахгүй. Алдааны body-ийн яг result утгыг спецификаци заагаагүй тул зохиомол ERROR код шаардаагүй.

## Бодит үр дүн — session-ийн нотолгоо

```text
HTTP/1.1 200 OK
Content-Type: application/json
Date: Fri, 16 Oct 2026 16:21:15 GMT
```

```json
{"result":"OK"}
```

Эвдэрсэн JSON-ийг амжилттай мэт 200 OK гэж хариулсан. Энэ нотолгоогоор ном өгөгдлийн санд нэмэгдсэн эсэхийг дүгнээгүй.

## Ноцтой байдал

Major — хүсэлтийн формат буруу байхад API зөвшөөрсөн мэт хариулж, хэрэглэгч систем алдааг ялгах боломжгүй болно.
